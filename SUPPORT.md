# Support

## Supported requests

- Installation and local execution questions.
- Reproducible audit-engine defects.
- False-positive and false-negative audit rules with public evidence.
- Documentation corrections and compatibility reports.

Use GitHub Issues:

`https://github.com/yangjing6213-dev/seo-geo-smart-audit-skill/issues`

## Not supported

- Guaranteed indexing, ranking, traffic, or AI citation outcomes.
- Access to private sites or authenticated dashboards.
- Submission to search-engine consoles on a user's behalf.
- Emergency response, private consulting, or a guaranteed response time.

Security issues must follow [SECURITY.md](SECURITY.md), not public Issues.
