# Security Policy

## Supported versions

Security fixes are applied to the latest code on the default branch. Historical versions are not guaranteed to receive fixes.

## Reporting a vulnerability

Use the repository's private GitHub Security Advisory form:

`https://github.com/yangjing6213-dev/seo-geo-smart-audit-skill/security/advisories/new`

Do not open a public issue before coordinated disclosure. Remove credentials, private target URLs, customer reports, cookies, and personal data from evidence. Maintainers will acknowledge the report when practical, but no response-time SLA is promised.

## Security boundary

SearchScope is intended for read-only inspection of public HTTP(S) websites. Reports involving private-network access, credential use, form submission, production writes, or bypassing a target site's access controls are outside the supported design.
